# 7-Zip Portable

A lightweight, portable version of the popular 7-Zip archiver.  
Use this to extract and compress files on Windows without installation.

---

## About

This is an addon designed to work with the [YouTube Toolkit](https://github.com/MoreKronos/Youtube-Toolkit) project. It provides portable 7-Zip functionality to assist with archive extraction and management within the toolkit.

---

## Features

- Portable: No installation required, just run the executable  
- Supports all common archive formats: `.zip`, `.7z`, `.rar`, `.tar`, and more  
- High compression ratio with fast performance  
- Easy to use via command line or GUI  

---

## Usage

1. Download or clone this repository.  
2. Extract the contents to any folder or USB drive.  
3. Run `7z.exe` or `7zFM.exe` directly — no installation needed!  
4. Use within YouTube Toolkit as your extraction tool.

---

## Requirements

- Windows 7 or later  
- No dependencies or admin rights required
